# 花园日历 (Garden Calendar) - 首页与基础路由设计规格

## 1. 项目背景
花园日历是一个结合时间管理与 3D 视觉反馈的 Web 应用。由于整个项目涉及复杂的图形渲染与数据流，因此采取分阶段开发。本项目计划（阶段一）专注于搭建全局架构、前端路由系统以及实现具备高度视觉冲击力的首页交互。

## 2. 架构与技术栈
- **框架**: Next.js 14+ (App Router) 
- **语言**: TypeScript
- **样式**: Tailwind CSS
- **动画**: Framer Motion
- **包管理器**: npm (或 pnpm)

## 3. 核心功能需求

### 3.1 页面路由结构
应用包含三个主要视图：
1. `/` - 首页（欢迎视图）
2. `/schedule` - 日程页面（打卡与时间管理）
3. `/garden` - 花园页面（3D 数据展示）

### 3.2 布局设计 (Layout)
- **全局导航栏 (Navbar)**：
  - 位于页面顶部，悬浮设计（`fixed` 或 `sticky`）。
  - 使用毛玻璃（Glassmorphism）效果（`backdrop-blur`），确保不遮挡背景内容。
  - 包含导航链接：“首页”、“日程”和“我的花园”。
- **页面切换动画**：
  - 使用 Framer Motion 的 `<AnimatePresence>`，页面在路由切换时拥有平滑的淡入淡出或滑动过渡。

### 3.3 首页交互设计 (Home Page)
- **全屏背景**：
  - 页面背景是一张全屏高清图片（或循环播放的视频）。
  - 开发阶段使用占位背景图（`public/hero-bg.jpg`），上线后可自由替换。
- **前景层 (Hero Section)**：
  - 居中的毛玻璃卡片（Glass Card），包含：
    - 主标题：“你的花园日历”（暂定）。
    - 副标题：“种下时间，收获花园”。
    - 操作按钮 (CTA)：“开始打卡” 和 “去看看花”。
- **动画细节**：
  - 页面初次加载时，标题和按钮依次进行带有弹性阻尼（Spring physics）的淡入上升动画。
- **无缝滚动跳转**：
  - **关键交互**：监听首页的鼠标滚轮向下滚动（`wheel` 或 `touchmove`）。
  - **行为**：一旦检测到向下滚动，拦截默认滚动行为，直接触发路由跳转 `router.push('/schedule')`，利用页面切换动画平滑过渡到“日程页面”，并默认定位到当天的日程。

## 4. 数据与状态管理
- 阶段一只建立空壳结构。
- 在顶层（`app/layout.tsx` 或 Provider 组件中）预留基于 React Context 的状态管理器结构，为未来全局共享“日程数据”打下基础。

## 5. 验收标准
- 成功运行 Next.js 并在本地访问。
- 导航栏在所有页面可见且工作正常。
- 首页背景满屏，毛玻璃卡片和文字居中显示，具备加载动画。
- 在首页向下滚动鼠标能自动平滑跳转至 `/schedule` 路由。
- Framer Motion 提供的页面路由切换无卡顿。

## 6. 后续阶段（不在本规格范围内）
- 阶段二：日程页面的详细时间分块逻辑、拖拽与打分系统、本地数据存储（LocalStorage / IndexedDB）。
- 阶段三：花园页面的 Three.js 场景搭建、基于日程分数的 3D 植物生成与渲染。
