# 花园日历 (Garden Calendar) - 日程页面设计规格

## 1. 项目背景与目标
作为花园日历的核心数据引擎，日程页面 (`/schedule`) 承担着记录用户每天时间分配、计算当日总分，并为最终的 3D 花园生成提供数据依据的职责。设计的核心目标是**极速、直观、充满交互乐趣的录入体验**。

## 2. 页面架构 (Layout)
页面采用经典的三栏式（或响应式两栏式）布局：
1. **左侧：事件配置面板 (Event Configuration)**
2. **中间：主时间轴面板 (Daily Timeline)**
3. **右侧/顶部：健康与数据面板 (Health & Stats)**

## 3. 功能需求详述

### 3.1 事件配置面板 (Event Config)
- **展示**：以彩色胶囊（Chip/Tag）的形式列出所有用户自定义事件。
- **属性**：每个事件包含 `名称`（如“睡觉”）、`基础分数`（如 10分/30分钟）、`颜色`（用于涂抹时间块）。
- **编辑能力**：用户可以点击“+”添加新事件，或长按/右键编辑现有事件（修改名称、分数、颜色）。
- **交互状态**：
  - 点击选中某事件，该事件呈高亮（Active）状态。
  - 选中后，用户的鼠标指针（在桌面端）变为“画笔”状态，表示已准备好向时间轴填涂。

### 3.2 核心时间轴交互 (Timeline & "Paint" Interaction)
- **粒度划分**：时间轴从 0:00 到 24:00，按 **30分钟** 划分为 48 个基础时间块。
- **画笔涂抹 (Drag to Paint)**：
  - 用户在左侧选中事件（如“睡觉”）后，在时间轴的起始方块上按下鼠标左键，并拖动到结束方块。
  - 鼠标经过的方块会立刻被填充上该事件的颜色。
  - 这使得用户能以极快速度一次性填入连续 8 小时的睡眠，或 2 小时的学习。
- **视觉反馈与动效 (Framer Motion)**：
  - **悬停**：鼠标滑过空方块时，方块显示所选颜色的 20% 透明度预览。
  - **填充**：方块被填涂的瞬间，伴随轻微的缩放回弹动画（Spring scale: 0.95 -> 1.05 -> 1.0），增强“按压填涂”的物理感。
  - **总分联动**：每次松开鼠标完成一段填涂，顶部总分执行数字滚动递增动画。

### 3.3 日期导航 (Date Navigation)
- 默认进入 `/schedule` 时显示**当天**的日程。
- 顶部中央显示当前日期（如“4月18日 周六”）。
- 两侧有快捷的前后天切换箭头（`<` 和 `>`）。
- 点击日期文本，展开一个月历弹窗（Calendar Picker），允许快速跳转到历史或未来日期。

### 3.4 隐藏分机制 (Weight Tracking)
- 提供一个专门的输入框记录当日体重。
- **积分逻辑**：输入体重后，系统自动对比“昨天”的体重记录。
  - 若 `Today < Yesterday`：触发隐藏加分（默认 +10）。
  - 若 `Today > Yesterday`：触发隐藏扣分（默认 -10）。
  - 分数直接汇入“今日总分”中。
- **自定义配置**：提供设置项，允许用户修改增/减重对应的分数值。

## 4. 数据结构 (Data Model)
数据初步采用 Zustand 或 React Context 存储于客户端内存/LocalStorage。
```typescript
// 1. 事件配置字典
type EventConfig = {
  id: string; // uuid
  name: string;
  scorePerSlot: number; // 30分钟的分数
  color: string; // hex or tailwind class
};

// 2. 每日记录模型
type DailyRecord = {
  date: string; // "YYYY-MM-DD"
  weight: number | null; // 当日体重
  weightScore: number; // 产生的隐藏分
  // 48 个槽位，对应 00:00, 00:30 ... 23:30
  timeBlocks: Record<string, string>; // { "00:00": eventId, ... }
  totalScore: number; // 动态计算
};

// 3. 全局设置
type GlobalSettings = {
  weightLossBonus: number; // default: 10
  weightGainPenalty: number; // default: -10
};
```

## 5. UI 风格
- 保持与首页一致的自然、清新风格。
- 背景采用柔和的米白色或极浅的绿色。
- 时间块边缘采用圆角（`rounded-md`），填充颜色使用低饱和度、高明度的马卡龙色系（Macaron Colors），避免刺眼。
- 大量使用毛玻璃面板承载侧边栏和配置区域。

## 6. 验收标准
- 事件配置区可以新增/选中事件。
- 时间轴精确分为 48 格（30分钟/格）。
- **拖拽涂抹**功能完美生效，并伴有弹性动画。
- 填入事件后，总分能实时响应并进行滚动动画。
- 体重输入能根据前后日差值正确计算隐藏分。
- 日期可以自由切换，切换后数据独立。
