# 日程页面重构 (Schedule Page Refactor) - 设计规格

## 1. 目标
修复日程页面现有布局不合理、空间浪费的问题，实现 48 个时间块的完美平铺无滚动；同时实现“体重组件”的紧凑化左置，以及“添加事件”的内联表单与随机防重颜色分配功能。

## 2. 页面布局重构 (Layout)
- **全局由 3 栏变为 2 栏**：
  - **左侧边栏 (w-72)**：包含紧凑版的 `HealthPanel` (上) 和 `EventPanel` (下)。
  - **右侧主区 (flex-grow)**：包含 `Timeline`。
- **高度控制**：整个页面依然占据屏幕剩余高度（`h-[calc(100vh-4rem)]` 或类似的满屏减去导航栏高度），内部元素不应出现全局滚动条。

## 3. 左侧组件重构
### 3.1 健康小组件 (Health Panel)
- 从右侧移至左侧最上方。
- 去除多余的留白，采用更紧凑的横向布局（体重输入框和按钮同行，小字提示紧随其后）。

### 3.2 事件配置面板 (Event Panel)
- **内联表单交互**：
  - 点击“添加事件”按钮后，按钮隐藏，原地出现一个包含两个输入框（事件名称、分数/30分钟）和“确定/取消”按钮的表单。
- **随机防重颜色分配**：
  - 系统预设一组 Tailwind 背景色（如 `bg-red-200`, `bg-blue-200`, `bg-purple-200`, `bg-teal-200` 等 15-20 种）。
  - 保存新事件时，获取当前已使用的颜色集合。
  - 从预设池中过滤掉已使用的颜色，并随机抽取一个赋给新事件。如果所有颜色均已使用，则不再过滤直接随机抽取。

## 4. 时间轴平铺重构 (Timeline 4-Column Grid)
- **网格布局**：
  - 使用 CSS Grid (`grid-cols-4`) 将时间轴分为 4 列。
  - 48 个时间块分为 4 组（0-6点、6-12点、12-18点、18-24点），每组 12 个块。
- **列头**：
  - 每列顶部增加柔和的标识符（如“凌晨 0:00-5:30”、“上午 6:00-11:30”等）。
- **高度自适应**：
  - 时间块自身不再写死固定高度（如 `h-12`），而是利用 `flex-grow` 或 `h-full` 填满其容器，使得 12 个块刚好铺满一列屏幕高度，彻底消灭滚动条。
- **保留原有交互**：
  - 现有的“画笔拖拽涂抹”功能必须在多列网格布局中继续正常工作。

## 5. 验收标准
- 日程页面左右两栏布局合理。
- 添加事件功能生效，且每次分配的颜色不与现有事件重复。
- 时间轴呈现 4 列网格，48 个块完美铺满一屏，无需上下拖动即可查看全天日程。
- 画笔涂抹操作在不同列之间依然有效。
